# ClawCore Chat Panel MVP

작은 데스크톱 채팅창처럼 쓸 수 있는 로컬 웹 UI야.

## 실행
ClawCore 루트에서:

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서:
- <http://127.0.0.1:8000/apps/chat/>

## 목적
- 자연어 작업 요청 입력
- 빠른 액션 버튼
- ClawCore task / desktop operator 연결을 위한 UI 뼈대

현재는 UI MVP이며, 다음 단계에서 자연어 입력을 실제 operator/task 실행으로 연결할 수 있음.
